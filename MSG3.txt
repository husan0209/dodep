Third round, from the failures the second round's runs exposed.

Go: libs/proto/gen was still empty in every ci-go.yml job
- ci-go.yml never generated the protobuf stubs, so a clean checkout failed
  with "no required module provides package
  github.com/opus-casino/proto/gen/go/..." in lint, test and security alike.
  Added the pinned buf 1.73.0 + make -C libs/proto gen-go step to all three
  jobs, with working-directory "." so the relative make path resolves.
- GO_VERSION 1.21 -> 1.26 (modules declare go >= 1.24).
- The golangci-lint action runs the linter itself, so the extra
  "Run golangci-lint" step duplicated the run; removed, and fixed the
  comment indentation.

Python
- analytics could never be installed: pyproject required
  sqlalchemy>=2.0 while apache-airflow>=2.8 pins sqlalchemy<2.0, so both
  "pip install -e .[dev]" and the new requirements.txt failed with
  ResolutionImpossible. Nothing in src/ imports airflow, so it is out of
  the dependency list with a comment; both install paths now resolve.
- bandit flagged B101 on every pytest assert. Excluded tests/ via
  [tool.bandit] and pointed the workflow at the config with -c, rather
  than skipping the whole check.
- fraud-ml bandit findings fixed rather than suppressed: md5 cache key ->
  sha256 (B324, non-security use), hardcoded /tmp -> tempfile.gettempdir()
  honouring FEATURE_CACHE_DIR (B108), empty default password removed from
  ClickHouseClient so it is required (B107), and the deliberate
  0.0.0.0 container bind annotated with the reason (B104).
  ClickHouseClient's password moved ahead of user so it can stay required.

Rust
- wallet-core's WalletError was missing DatabaseError, ConcurrencyConflict
  and TransactionNotFound, which 38 call sites across repositories/ and
  wallet_service.rs construct: "no variant or associated item named
  DatabaseError". Added them with messages and mapped them into AppError.
  crate-local errors drop from 102 to 63.
