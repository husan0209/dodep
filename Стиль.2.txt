## 2. СТРАТЕГИЯ ЗАГРУЗКИ ШРИФТОВ

**Проблема:** FOUT при медленном соединении, прыжки баланса.

```
РЕШЕНИЕ:

1. CRITICAL PATH (отображается сразу):
   font-family: 'JetBrains Mono', monospace;
   font-display: swap;
   preload: <link rel="preload" href="/fonts/jetbrains.woff2" 
             as="font" type="font/woff2" crossorigin>
   
2. FALLBACK METRIC MATCHING:
   Настроить @font-face с font-metric-override:
   — ascent-override: 80%
   — descent-override: 20%
   — line-gap-override: 0%
   — advance-override: 0.5 (монопространственный fallback)
   
   Системный monospace шрифт (Consolas/Monaco) имеет
   почти идентичные метрики с JetBrains Mono.
   Layout shift < 0.01 CLS.

3. SKELETON ДЛЯ БАЛАНСА:
   Пока шрифт грузится — показывать skeleton:
   ┌──────────────┐
   │  $••,•••.••  │  ← серые кружки вместо цифр
   └──────────────┘
   Смена на реальные цифры — через opacity fade (100ms)

4. SUBSET LOADING:
   Шрифт JetBrains Mono загружать только цифры + знаки:
   U+0030-0039, U+0024, U+002E, U+002C, U+002B, U+002D
   Это ~5KB вместо ~40KB полного шрифта.
```

## 6. СИНХРОНИЗАЦИЯ СЧЁТЧИКА ДЖЕКПОТА

```
ПРОБЛЕМА: счётчик «прыгает назад» при обновлении.
ПРИЧИНА: CSS-анимация интерполирует, а серверная сумма
         выросла меньше, чем ожидалось.

РЕШЕНИЕ — ADAPTIVE INTERPOLATION:

1. Сервер отправляет реальную сумму каждые 5 секунд.
   { type: "jackpot_update", tier: "MEGA", value: 2847291.84 }

2. Клиент знает: предыдущее значение = 2847290.00,
   текущее = 2847291.84, delta = 1.84 за 5 секунд.

3. Расчёт скорости роста (velocity):
   velocity = delta / interval = 1.84 / 5 = 0.368/сек

4. Анимация между обновлениями:
   currentValue += velocity * frameDelta * randomFactor(0.8, 1.2)
   
   randomFactor добавляет «дрожание» — счётчик выглядит
   живым, а не линейным.

5. При получении нового значения от сервера:
   — Если serverValue > clientValue → анимация к serverValue
   — Если serverValue <= clientValue → мгновенная установка
     (защита от «прыжка назад», но с fade-flash эффектом)

6. Логирование: velocity не должна превышать 10/сек
   (защита от бага в данных)
```

```

│  ┌─────────────────────────────────────────────────┐    │

│  │ 2. Fallback: Intl.DateTimeFormat().timeZone     │    │
│  │ 3. Fallback: UTC (если определить не удалось)   │    │

│  │      switch(format) {                            │    │

│                                                         │

│       click_id: "uuid",                                 │
│       ref_code: "PARTNER123",                           │
│       utm: {source, medium, campaign, content},         │
│       ip: "x.x.x.x",                                   │
│       ua: "Mozilla/5.0...",                             │

│     }                                                   │
│                                                         │
│  3. Клиентская сторона:                                 │
│     — Cookie: ref=PARTNER123, TTL = 30 дней              │

## 17. ПОВЕДЕНИЕ ПРИ LOGOUT

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ОТКРЫТАЯ ИГРА (casino iframe):                         │
│  1. iframe немедленно закрывается                       │
│  2. Платформа отправляет API: POST /api/game/session/end │
│  3. Провайдер фиксирует состояние                        │
│  4. При следующем входе:                                 │
│     — Если сессия была активна < 24ч →                  │
│       показываем toast: "Вы играли в Gates of Olympus"   │
│       + кнопка "Продолжить"                              │
│     — Если > 24ч → сессия считается завершённой          │
│                                                         │
│  КУПОН С ВЫБРАННЫМИ ИСХОДАМИ:                          │
│  1. Сохраняется в localStorage с TTL = 1 час            │
│  2. При логине: проверка localStorage                    │
│  3. Если TTL жив → восстановление купона:               │
│     Toast: "У вас есть неоформленный купон               │
│     с 2 исходами"                                        │
│  4. Если TTL истёк → очистка                            │
│  5. При logout → НЕ очищаем сразу (ждём TTL)           │
│  6. Если другой пользователь залогинился на этом         │
│     устройстве → очистка localStorage                   │
│                                                         │
│  НЕЗАВЕРШЁННАЯ ТРАНЗАКЦИЯ ДЕПОЗИТА:                    │
│  1. Если пользователь перешёл на платёжный шлюз          │
│     (3DS, банк) → logout невозможен до возврата         │
│  2. При закрытии вкладки:                                │
│     — Транзакция завершается на стороне платёжного       │
│       шлюза                                              │
│     — Callback/webhook обрабатывается                    │
│     — При следующем входе:                               │
│       Toast: "Депозит $500 обработан"                    │
│       или: "Депозит $500 не удался. Средства не          │
│       списаны."                                          │
│  3. Если транзакция зависла (нет callback за 30 мин):    │
│     — Статус: PENDING                                    │
│     — Push: "Статус вашего депозита уточняется"          │
│     — Служба поддержки связывается автоматически          │
│                                                         │
│  SOFT LOGOUT vs HARD LOGOUT:                            │
│  ┌─────────────────────────────────────────────────┐    │
│  │ Soft Logout (таб в браузере закрыт):            │    │
│  │ — Session timeout: 30 минут неактивности         │    │
│  │ — При возврате: проверка сессии →                 │    │
│  │   если жива → авто-вход                          │    │
│  │   если истекла → экран входа                     │    │
│  │                                                  │    │
│  │ Hard Logout (пользователь нажал "Выйти"):       │    │
│  │ — Все локальные данные очищаются                 │    │
│  │ — Session invalidated на сервере                 │    │
│  │ — Требуется повторный вход                       │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 19. МУЛЬТИВАЛЮТНОСТЬ И КУРСЫ

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  АРХИТЕКТУРА:                                           │
│  — Base currency платформы: EUR (внутренний расчёт)     │
│  — Display currency: то, что видит пользователь         │
│  — Provider currency: валюта провайдера (обычно EUR)    │
│                                                         │
│  ПОТОК:                                                 │
│  1. Пользователь выбрал USD                              │
│  2. Баланс отображается в USD: $1,000                    │
│  3. Внутри: $1,000 = €920 (курс 1.087)                  │
│  4. Пользователь делает ставку $10 в слоте               │
│  5. Платформа отправляет провайдеру: €9.20               │
│  6. Провайдер списывает €9.20, возвращает €50 выигрыш    │
│  7. Платформа конвертирует: €50 = $54.35                 │
│  8. UI показывает: +$54.35                               │
│                                                         │
│  КУРСЫ:                                                 │
│  — Источник: Open Exchange Rates API (или Fixer.io)     │
│  — Обновление: каждые 15 минут                           │
│  — Фиксация на транзакцию: курс фиксируется в момент     │
│    создания транзакции (не в момент исполнения)           │
│  — Пользователю НЕ показывается курс в казино            │
│    (это создаёт путаницу)                                │
│  — Пользователю ПОКАЗЫВАЕТСЯ курс при депозите/выводе:   │
│    "Вы вносите $100 (≈ €92.00 по курсу 1.087)"          │
│                                                         │
│  EDGE CASES:                                            │
│  — Курс изменился между добавлением в купон и            │
│    подтверждением ставки → курс фиксируется при          │
│    подтверждении, а не при добавлении                    │
│  — Криптовалюты: курс обновляется каждые 1 минуту        │
│    (высокая волатильность)                                │
│  — Отображение: 8 знаков после запятой для крипты        │
│    (0.00012345 BTC)                                      │
│                                                         │
│  ВЫБОР ВАЛЮТЫ ПРИ РЕГИСТРАЦИИ:                         │
│  [USD ▼] [EUR] [GBP] [RUB] [BTC] [ETH] [USDT]          │
│  ⚠️ Валюту нельзя изменить после регистрации.             │
│  Для смены валюты: обращение в поддержку.                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

│     — Кэф возвращается к default                         │
│     — Исход удаляется из купона                          │
│     — Toast: "❌ Не удалось добавить. Маркет закрыт."     │
│                                                         │
│  ПОДТВЕРЖДЕНИЕ СТАВКИ:                                  │
│  1. UI: кнопка "Поставить" → loading state               │
│  2. POST /api/bets/confirm                               │
│  3. Ожидание: 2 секунды (с анимацией загрузки)           │
│  4. 200: toast "✅ Ставка принята" + купон очищается     │
│  5. 409 (кэф изменился):                                 │
│     — Модальное окно с новым кэфом                       │
│     — Пользователь решает: принять или отменить           │
│  6. 403 (лимит): "❌ Превышен лимит ставки               │
│     ($50 на этот маркет)"                                │
│  7. Timeout (>10 сек):                                   │
│     — Toast: "⏳ Ставка обрабатывается..."                │
│     — Авто-проверка статуса через polling каждые 5 сек   │
│     — Через 60 сек: "Ставка не подтверждена.             │
│       Обратитесь в поддержку."                            │
│                                                         │
│  БАЛАНС ПРИ ОПТИМИСТИЧЕСКОМ ОБНОВЛЕНИИ:                │
│  — При добавлении в купон: баланс НЕ списывается         │
│    (ставка ещё не сделана)                                │
│  — При подтверждении ставки:                             │
│    1. Баланс оптимистично списывается                    │
│    2. Показ: -$50 (с анимацией уменьшения)               │
│    3. Если сервер отклонил → баланс возвращается          │
│       с анимацией увеличения                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
